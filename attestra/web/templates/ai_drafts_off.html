AI drafts are on for Attestra but switched off for this client ({{ e.tenant.name }}) by ATTESTRA_AI_TENANTS_OFF. Remove this client's id ({{ e.tenant_id }}) from that list and restart Attestra to use them here.

{% else %}

AI drafts are optional and off by default. While they are off, nothing is sent to any AI service and reports use their normal template text.

To switch them on

  1. Set ATTESTRA_AI_NARRATIVES=on.
  2. Choose a provider:
    • ATTESTRA_AI_PROVIDER=ollama for a local model, no API key needed (set ATTESTRA_AI_MODEL, for example llama3.1).
    • ATTESTRA_AI_PROVIDER=openai for any OpenAI-compatible service, with ATTESTRA_AI_BASE_URL, ATTESTRA_AI_MODEL and ATTESTRA_AI_API_KEY.
  3. Restart Attestra and reload this page.
{% endif %}

Full setup and data-protection details: docs/AI_NARRATIVES.md in the Attestra folder.
