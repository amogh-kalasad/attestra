# Compliance library external review

Export the control library with `attestra compliance-export > library.csv` and send it to a QSA / ISO lead auditor before production use.

| Field | Value |
| --- | --- |
| Library version | Attestra 0.1.0 Phase 3 |
| Exported file | `attestra/compliance/data/controls.yaml` + `cwe_map.yaml` |
| Reviewer | _pending — assign QSA / ISO lead auditor_ |
| Review date | _pending_ |
| Outcome | _pending — record findings and signed off version_ |

Control titles are paraphrased. Verify every reference against licensed PCI SSC, ISO/IEC 27001:2022, and AICPA TSC source texts.
